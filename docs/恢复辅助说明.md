# 长时间传输故障的辅助恢复

Windows 监测器默认在连续传输故障达到 180 秒后调用 `VpnRecoveryHelper.exe`。同一轮持续故障最多每 600 秒再次评估。短时波动、HTTP 403/429/5xx 或认证要求不会触发策略切换。

辅助模块核对当前监听代理端口所属核心、受支持本机控制器、规则与代理组链。仅安装某种代理核心，或配置中存在自动组，并不代表当前 Codex 流量已经受该策略保护。

## 满足条件时的行为

- OpenAI 已经过未人工固定的 fallback/url-test：交给原生核心管理，不重复切节点。
- OpenAI 的四个域名族由 DOMAIN-SUFFIX 显式路由到同一个专用 selector，且存在未固定、有可用性证据的自动子组：请求前重读规则、组类型、成员、当前选择及固定状态；确认没有可见变化后，最多发出一次选择请求，并读取结果验证。
- 本地端口关闭、路由未知、共享组、没有自动子组、人工固定或接口不受支持：记录原因，保持当前配置。

不会新建代理组、重载代理核心、修改订阅、切换 GLOBAL 或共享整机节点、解除人工固定、删除连接、启动或关闭代理软件、关闭或重启 Codex，也不会自动重发任务。已断开的 TLS/WebSocket 不能由策略切换无缝续接。

控制接口不提供原子比较并交换。复核和选择之间仍存在短暂竞争窗口；节点服务器或凭据的同名变化也未必能被控制器完整暴露。检测到可见结构变化时模块停止操作，不反向覆盖用户的后续选择。被监测的 Codex 原进程退出时，辅助请求取消。

## 禁用辅助

在 PowerShell 7 中调用启动器并添加 `-NoWatchdog`，可跳过启动连接监测器；这一开关不会停止已经运行的监测器。监测器脚本自身提供 `-NoVpnAssist` 开关，可保留监测并禁用线路辅助。后者需要通过自定义监测器调用传入，默认双击启动入口不会传入该开关。

运行日志只记录固定状态、动作、客户端标签和说明，不记录订阅、节点凭据、控制器 secret 或 API 响应正文。第三方许可位于 `licenses`。
